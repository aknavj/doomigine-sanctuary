# Doomigine - Sanctuary Demo

> When Doom 3 meets Unigine: A reverse-engineered backport of the classic Unigine Sanctuary benchmark running on vanilla id Tech 4.

## About Doomigine Sanctuary

Doomigine Sanctuary is an experimental tech demo and map mod that brings the iconic Unigine Sanctuary benchmark scene into the vanilla Doom 3 (id Tech 4) engine. Think of it as a retro-port—allowing older hardware and classic engine enthusiasts to experience the Sanctuary environment natively inside Doom 3.

## The Concept

During the early days of Unigine 1, its SDK and converter tools natively supported importing standard id Tech 4 formats—including .map, .ase, .md5mesh, and .md5anim. Doomigine Sanctuary flips that workflow completely upside down: instead of bringing Doom 3 assets into Unigine, this project takes the geometry, atmosphere, and spirit of Unigine's famous Gothic benchmark and backports it into Doom 3.

## Key Highlights

- Engine Mashup: Bridges the visual style of the 2007 Unigine Sanctuary benchmark with the classic unified lighting and stencil shadows of id Tech 4.

- Vanilla Compatibility: Built to run on the standard, unmodified Doom 3 engine without requiring modern source-port overhauls.

- Hardware Time Capsule: Reimagines a benchmark once meant to push DirectX 10/OpenGL GPUs so it can run on vintage mid-2000s hardware.
